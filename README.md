# SGX VI

SGX VI is an SGODX project focused on the SGX VI interactive experience and image generation platform.

The project is developed with Astro and React and deployed through Vercel.

## Development

```bash
npm install
npm run dev
npm run build
```

Environment variables contain sensitive configuration and must never be published. Use `.env.example` as the reference for local setup.
